# 🐍 Snake Game

A simple and interactive **Snake Game** built using **HTML, CSS, and JavaScript**.

The goal of the game is to control the snake, eat the food, increase your score, and avoid hitting your own body. When the snake reaches the wall, it wraps around and appears from the opposite side.

## 🎮 Features

* 🐍 Classic Snake gameplay
* 🍎 Randomly generated food
* 📈 Score tracing 
* 🔄 Snake wraps around when it reaches a wall
* 💥 Game ends when the snake hits its own body
* ⌨️ Keyboard controls
* 📱 Simple and responsive interface
* ⚡ Lightweight — no external libraries required

## 🛠️ Technologies Used

* **HTML5** – Structure of the game
* **CSS3** – Styling and layout
* **JavaScript** – Game logic and DOM manipulation

## 🎯 How to Play

1. Start the game.
2. Use the **Arrow Keys** to control the snake:

   * ⬆️ Up
   * ⬇️ Down
   * ⬅️ Left
   * ➡️ Right
3. Eat the food to increase your score.
4. The snake grows after eating food.
5. If the snake touches its own body, the game ends.
6. If the snake reaches a wall, it comes out from the opposite side.
